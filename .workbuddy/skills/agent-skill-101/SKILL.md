# Agent Skill 101 — 一分钟学会 Agent Skill（含分层测验与来源）

> **执行前必读**：当本技能被触发，须先读 `references/agent-skill-knowledge.md`（知识底座，含每条的权威来源）与 `references/quiz-engine.md`（分层自适应规则），再产出交付物。交付物中的知识点内容与来源链接必须严格取自 knowledge 文档，不得另造来源 URL。

## 一、职责概述（本技能产什么）

当学习者想弄懂"Agent Skill"时，产出一份**能一分钟扫完核心要点 + 能做分层自适应用题 + 每题/每点标注权威来源链接**的学习材料（默认交付为自包含 HTML，可离线打开；也可按需给 Markdown 版）。

### 为什么分层测验 + 来源是硬要求
- 分层：让测试适配真实水平——**答对往上一档升、答错往下一档降**，学习者在适合自己的难度里走完，不会因为全难题劝退或全简单题虚高。
- 来源：材料**必须**告诉学习者每块知识从哪来、给出可点链接，保证可核查、可跟进。

## 二、知识框架（六块，秒懂 Agent Skill）

产出材料正文须覆盖以下六点（细节与出处以 knowledge 文档为准）：

1. **概念**：Skill = 打包好的"能力扩展包 + 自带说明书"，类比"实习生上岗 SOP 手册"。
2. **内部结构**：`SKILL.md`（必填）+ `scripts/`（可执行、不占上下文）、`references/`（用到才读）、`assets/`（复制即用）。
3. **frontmatter 必填项**：`name` + `description`（description 决定何时触发）；自建技能加 `agent_created: true`。
4. **三级加载（Progressive Disclosure）**：元数据(常驻)→SKILL.md(触发时)→资源(按需)，省"脑容量"。
5. **使用流程**：扫描→触发→取用→执行→沉淀(把可复用方法沉淀成新技能)。
6. **来源纪律**：每条知识给真实来源；能列 URL 列 URL，本机权威文件标注路径。

## 三、正文可视化建议

- 用"实习生类比"开篇，降低理解门槛。
- 结构/分层/流程尽量用**图示**（结构树、三级加载表格、升降流程图）。
- 每块知识紧跟一个"📎 来源"引用块，样式与正文区分开。

## 四、分层测验（硬性规则，务必按 quiz-engine.md 实现）

- 出题走 **E(入门) → M(进阶) → H(挑战)** 三档，初始 E，从对应档题库抽题。
- **答对 → 升一档**；**答错 → 降一档**（已在 E 则留 E 并累计保底）。
- 题数上限 N（建议 12）；H 档连续答对 2 题可提前通关。
- 结束时按"曾达最高档 + 结束档位"给学成等级（🏆挑战大师 / 🎖进阶高手 / 📗进阶学员 / 📘入门学员）。
- E 档累计答错 ≥3 → 友好提示回炉，不算失败。

### 题库分层原则
- 入门 E：记忆/识别（如"SKILL.md 是否必填""三级加载分哪级"）。
- 进阶 M：理解/应用（如"references 为何放 references/""description 何时触发"）。
- 挑战 H：分析/综合（如"为一个新任务设计技能结构""判断某文件该放 scripts 还是 assets"）。
- 每档 ≥ 4 道，题干、选项、正确答案、难度、**考点来源**五要素齐全。
- 题干常考考点务必来自 knowledge 文档，避免自造"伪知识"。

## 五、产出 HTML 的工程要求（吸取历史 bug 教训）

- **判分可靠**：选项用 `<button>` + 显式 `.selected` 状态，由 JS 全权掌控；不要依赖 `<label>`+`input:checked` 那套（曾在预览环境中被判全错）。
- **即时反馈**：每题答完立刻显示 对✓/错✗ + "难度↑/↓" 提示，不做到最后才出分。
- **可见版本号**：页面角落标注版本，便于用户确认加载的是新版、排除缓存。
- **自包含**：全部 CSS/JS 内联，单文件可离线双击打开；避免依赖外链 CDN（离线不可用）。
- 判分链路完成后，用与页面同构的逻辑做一次**单元自测**再交付（单选/多选/升降均测）。

## 六、交付物落盘约定

- 默认保存为 `agent-skill-guide.html`（可交互学习卡）到用户指定目录/课程仓库根目录。
- 若本技能作为 WorkBuddy 技能被复用：产物存到调用方工作目录，文件名含 `agent-skill` 字样便于检索。
- 交付时向学习者说明：测验分层/升降为**本学习工具的设计规则**，知识点本体与来源来自官方/说明书（见每处来源）。

## 资源
- `references/agent-skill-knowledge.md` —— 六块知识的权威内容 + 每条来源链接（**产出材料的事实与链接来源**）。
- `references/quiz-engine.md` —— 分层自适应算法、定级与实现要求。
- `assets/agent-skill-guide.template.html` —— 可直接改写的学习页模板（含知识卡片、分层测验、来源引用块、版本号）。
- `assets/quiz-bank.js` —— 分层题库数据源（E/M/H 三档各 4 题，含来源与解析），页面内联题库应与之同源，新增题目须保持三档平衡并给出来源。
