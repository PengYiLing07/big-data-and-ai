# 分层自适应测验引擎说明

> `agent-skill-101` 技能的核心机制：测试题**按难度分层**，学习者**答对升级、答错降级**，用固定难度题库走出一条"自适应路径"，最终给出学成等级。
> 本文档供 AI 与前端实现共用，规则必须一致。

---

## 一、难度分层（固定）

把题库分成三档，每道题有一个**固定的难度标签**，不随答题表现改变：

| 档位 | 代号 | 难度 | 考察内容示例 |
|------|------|------|------------|
| 入门 | `E`（Easy） | 记忆/识别 | SKILL.md 是不是必填、三级加载分哪几级 |
| 进阶 | `M`（Medium）| 理解/应用 | 为什么 references 放 references/；description 何时触发 |
| 挑战 | `H`（Hard） | 分析/综合 | 设计一个技能的结构；判断哪个该放 assets |

规则：
- 每道题 `data-diff` 标注 `E`/`M`/`H`。
- 同档题目可备多道（建议每档 ≥ 4 道，避免重复刷同一题）。

---

## 二、难度自适应路径（答对升级 / 答错降级）

用**单题序列**推进，每题答完立即调整当前难度档位，再从对应档位抽下一题：

```
当前档位 level ∈ {E, M, H}

答对本题：
    level 升一档（E→M→H；H 已在最高则保持 H）
答错本题：
    level 降一档（M→E，H→M；E 已在最低则保持 E）
    （若 E 档答错，扣减一次"保底机会"，见判定）

抽题：从 level 对应档位的未作过题库中随机抽一题。
     若该档已抽完，可复用该档题目并提示"复习题"。
```

关键点：
- 走"**先入门**"路线：初始 `level = E`。
- **升级是即时反馈**：每题后显示"↑ 难度提升到 X" 或 "↓ 降回 X"，让学习者看清自己在哪。
- **到达 H 档时把连对计数归零**（`hardStreak = 0`）——"H 档连对通关"只在 H 档内累计，避免 E/M 档的对数被带入误判通关。
- 已经到达过 `H` 说明学习者有能力冲刺，即便偶尔答错降回 M 也符合"易错则降、巩固后再上"。

---

## 三、通关与等级判定

采用**题数上限 + 稳定难度**双条件，防止无限刷题，也防止一题侥幸升档：

- 结束条件（满足其一）：
  1. 答题数达到上限 `N`（建议 N = 12；可配）。
  2. 学习者在**最高档 H** 连续答对 ≥ 2 题 → 提前通关。

- 等级评定（**挑战大师须真正提前通关**，防止"刚到 H 档一次就对"被误判）：
  | 达成情况 | 学成等级 |
  |---------|---------|
  | 在 H 档连续答对 ≥2（`winByStreak`，提前通关） | 🏆 挑战大师 |
  | 曾达到 H，但结束时掉回 M/E（未连对通关）| 🎖 进阶高手 |
  | 未上过 H，结束 level = M | 📗 进阶学员 |
  | 未上过 H，结束 level = E | 📘 入门学员 |

- **保底机会**：E 档累计答错 ≥ 3 次 → 结束会话并提示"建议重看入门卡片再战"，不算完全失败，鼓励回炉。

## 四、对前端/实现的要求

- 判断题对错的比较必须读"用户实际选中项"而非外观 class（历史 bug 教训：用 button + `.selected` 显式状态，不要依赖原生 input:checked）。
- 每题作答后**即时**给出 对✓ / 错✗ + 难度变化提示。
- 完成后展示：总答题数、各档正确率、最终学成等级、错题回顾（含来源链接）。
