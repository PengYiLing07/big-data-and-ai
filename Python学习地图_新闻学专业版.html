LEARNING ROADMAP · PYTHON · 4 × 45 MIN

Python 四课时学习地图
180 分钟，从零基础到能用代码处理新闻素材

这套路线按 4 节课 × 45 分钟 = 180 分钟 的课堂时间设计，专为新闻学专业定制。 目标不是培养程序员，而是让你下课时手里有 4 个能跑的小脚本， 并且知道 Python 在新闻业务里该怎么用、用在哪。

4 节课 × 45 分钟 课前准备约 40 分钟（不计入课时） 课后作业每节约 30 分钟 结课产出：1 张图 + 1 段结论

!开始之前，先说清三件事

45 分钟一节课是很紧的。下面这三条决定了你能不能真的学会，而不是"上完就忘"。

① 环境搭建必须放在课前，不能占用课堂时间

安装 Python、装好 VS Code、跑通 print("hello")——请务必在第一节上课前完成（约 40 分钟，遇到问题提前找人或问 AI 解决）。课堂上我们只讲代码，不讲安装。这是 45 分钟课时里最容易失控的一环。

② 课堂上不追求"理解全部语法"，只追求"能跑出结果"

遇到暂时看不懂的地方，先记在便签上，继续跟着敲。四节课的目标是建立直觉 + 拿到可用脚本，深层的语法原理留到以后需要时再补。死磕一个细节，会挤掉整节课的动手时间。

③ 每节课都必须当堂敲完，课后作业是"换自己的数据重跑"

只看不敲等于没学。四节课的动手任务都控制在 15–20 分钟内可完成，你只要跟着敲就一定能跑通；课后作业不是新内容，而是把你自己的稿件、标题、表格替换进去再跑一遍。

1第 1 课（45 分钟）· 跑起来，会用变量和字符串

课堂目标：能看懂并改写一段 Python，让脚本替你数数字、切句子。

01

从第一行代码到新闻导语速检器

难度 ★☆☆☆☆ ｜ 关键词：变量、数据类型、字符串、输入输出

导入5 分钟
讲 + 跟敲20 分钟
自己动手15 分钟
小结5 分钟

这节课只讲这四点

  • 变量与命名：把"标题""字数"这些概念装进变量里
  • 四种基础类型：文字 str、整数 int、小数 float、真假 bool
  • 输出与输入：print() 打印结果，input() 让人输入内容
  • 字符串四件套：len() 数长度、split() 切分、replace() 替换、strip() 去空白，外加 f-string 拼接

课堂示例代码

# 新闻导语速检器
lead = "昨日下午，本市召开新闻发布会，就市民关心
的公共交通调价问题作出回应。"
lead = lead.replace("\n", "").strip()

sentences = [s for s in lead.split("。") if s]

print(f"总字数：{len(lead)}")
print(f"句子数：{len(sentences)}")
print(f"平均句长：{len(lead)/len(sentences):.1f} 字")
课堂动手（15 分钟，必须当堂敲完）

把示例代码跑通，然后加两行：用 input() 让程序读入一段导语，输出它的字数和句数。跑出结果就把代码存成 lesson1.py。

课后作业（约 30 分钟）

拿你自己写的 3 段稿件导语各跑一次，记下平均句长。想一想：多少字算"句子太长"？——这个判断标准由你定，代码只是替你数。

本节课刻意不讲

列表、字典、循环、函数、面向对象——全部留到后面。这节课只需要你熟悉"变量装东西、print 出结果"这一件事。

2第 2 课（45 分钟）· 列表、字典、循环与判断

课堂目标：一条新闻用变量存，十条就要用容器和循环——这是全课程最关键的一节。

02

打造一个标题批量筛选器

难度 ★★☆☆☆ ｜ 关键词：列表、字典、for 循环、if 判断

复习5 分钟
讲 + 跟敲20 分钟
自己动手15 分钟
小结5 分钟

这节课只讲这四点

  • 列表 list：一次装一批标题，会取第几个（索引）、会数个数（len）、会排序（sort）
  • 字典 dict：装一条结构化线索——标题、来源、关键词各占一个字段
  • for 循环：把列表里的每一条都拿出来看一遍
  • if 判断：满足条件的留下，不满足的跳过；配合计数就是统计

课堂示例代码

# 标题批量筛选器
titles = [
    "城市地铁票价调整方案公布",
    "老旧小区加装电梯提速",
    "地铁新线年底开通",
    "校园食堂价格引关注",
]

key = "地铁"
hit = 0

for t in titles:
    if key in t:
        hit = hit + 1
        print(f"命中：{t}")

print(f"共 {len(titles)} 条，其中 {hit} 条与
「{key}」相关")
课堂动手（15 分钟，必须当堂敲完）

把示例扩成 10 条自己的新闻标题，加入一个 keywords 列表（如 ["地铁", "小区", "学校"]），用一个循环统计每个关键词各命中几条。存成 lesson2.py。

课后作业（约 30 分钟）

从今天看到的新闻里抄 10 条标题，跑一遍你的筛选器。感受一下：当标题变成 100 条时，这个脚本还能帮你省多少时间。

本节课刻意不讲

while 循环、嵌套字典、列表推导式、函数定义——课堂上都不讲。有需要时再查，不影响你用起来。

3第 3 课（45 分钟）· 读写文件与 CSV 统计

课堂目标：把 Python 接到真实数据上——读一份表格，统计出结论，再写出新文件。

03

读一份采访记录，统计出结果

难度 ★★★☆☆ ｜ 关键词：文件读写、CSV、编码、统计输出

复习5 分钟
讲 + 跟敲18 分钟
自己动手17 分钟
小结5 分钟

这节课只讲这四点

  • 打开文件：with open("文件名", encoding="utf-8")——这是唯一需要背下来的固定写法
  • 读取表格：用 csv.DictReader 把每行变成字典，字段名就是表头
  • 统计：还是上一课的 for + if + 计数，只是数据从手打变成了读文件
  • 写回文件：把统计结果存成新的 CSV，方便交给同事或放进稿件

课堂示例代码

import csv

stat = {}

with open("采访记录.csv",
          encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        unit = row["单位"].strip()
        if unit:
            stat[unit] = stat.get(unit, 0) + 1

for unit, n in stat.items():
    print(f"{unit}　{n} 条")
课堂动手（17 分钟，必须当堂敲完）

用老师提供的（或自己造的）20 行采访记录 CSV 跑通统计，然后把结果写进一份新文件 统计结果.csv。存成 lesson3.py。

课后作业（约 30 分钟）

把 CSV 换成你熟悉的一份真实表格（发稿台账、活动名单都可以），只改字段名，跑出你自己的统计结果。顺便记一件事：中文乱码时，把 encoding 从 utf-8 改成 gbk 试试。

本节课刻意不讲

正则表达式、try/except 异常处理、批量清洗规则、pandas——这些是"进阶清洁工"，课堂上不讲。遇到报错时我会口头解释一句，但不展开。

4第 4 课（45 分钟）· 综合实战：词频分析与出图

课堂目标：把前三课串起来，走完"数据 → 分析 → 一张图"的链路，这是结课产出。

04

对一批标题做词频分析，生成一张图

难度 ★★★★☆ ｜ 关键词：第三方库、中文分词、词频统计、可视化

复习5 分钟
讲 + 跟敲15 分钟
自己动手20 分钟
小结5 分钟

这节课只讲这四点

  • 安装第三方库：一行 pip install jieba，从此能用别人写好的工具
  • 中文分词：jieba.lcut() 把标题切成一个个词，顺便过滤掉"的、了、在"这类没意义的词
  • 词频排行：用 Counter 数出出现最多的词，取前 10
  • 生成图表：用 matplotlib 画柱状图，或用 wordcloud 生成词云（课堂二选一即可，不贪多）

课堂示例代码

import jieba
from collections import Counter

titles = ["..."]        # 上一课的标题列表
stop = {"的", "了", "在", "和"}
words = []

for t in titles:
    for w in jieba.lcut(t):
        if len(w) > 1 and w not in stop:
            words.append(w)

for w, n in Counter(words).most_common(10):
    print(w, n)
课堂动手（20 分钟，结课产出）

准备 30 条同一选题的新闻标题（自己收集，存成文本或列表），跑出词频 Top10，并生成一张柱状图或词云图。存成 lesson4.py，图片保存到本地。

结课小结（最后 5 分钟）

把你生成的图展示给同学，用 一段话说明：这组数据里最突出的关键词是什么、它可能意味着什么、这个结论有什么局限。
——结论比图表重要。图只是证据，讲清"所以然"才是新闻能力。

本节课刻意不讲

网页抓取（requests）。它涉及请求头、反爬、合规等一堆问题，45 分钟内讲不透。请先用自己收集或学校提供的标题文本完成分析——课后想学抓取，我可以单独给你一份拓展指引。

6给 45 分钟课堂的三条纪律

课上坚决不做的三件事

  • 不现场装环境——课前 40 分钟必须解决，否则一节课就没了
  • 不追求理解全部语法——先记下来，继续跟着敲
  • 不在课上查复杂问题——卡住超过 3 分钟就举手，或先跳过

课后必须做的三件事

  • 把示例换成自己的数据重跑——这是"学会"的唯一标志
  • 把代码文件存好——四节课的脚本是你以后抄改的模板库
  • 每次报错都截图留存——同一个坑踩两次才是浪费

新闻学生常见的四个坑

  • 只看不敲——看懂了不等于会写，务必亲手敲一遍
  • 忽略缩进——Python 靠缩进划分代码块，空格和 Tab 混用必报错
  • 乱码就放弃——多半是 encoding 该填 gbk
  • 怕报错——从最后一行往上读，它才是原因

课后想继续学，按这个顺序

  • 第一步：函数 def，把反复用的代码打包起来
  • 第二步：pandas，处理真正的表格数据
  • 第三步：requests 抓取 + 合规注意事项
  • 第四步：找一个真实选题，完整做一次数据新闻

✦结课标准：180 分钟之后，你应该交得出什么

四节课结束时，请确认你手里有这四样东西。它们就是"学会基础运用"的全部证据：

  1. 四个能跑的脚本文件：lesson1.py ~ lesson4.py，每一个都对应一个真实的新闻场景。
  2. 一份自己的数据分析结果：用你熟悉的数据跑出来的统计或词频排行，不是示例数据。
  3. 一张能放进稿件的图：柱状图或词云，来自第四课的结课产出。
  4. 一段 300 字以内的结论：说清数据说明了什么、有什么局限——后半句是新闻人的专业优势。

这四节课完全没有覆盖

  • 函数与模块化、面向对象
  • 正则表达式与复杂文本清洗
  • pandas 数据框操作
  • 网页抓取与反爬应对
  • 网络爬取的合规边界判断

但你已经获得了更重要的东西

  • 不再害怕代码和报错信息
  • 知道 Python 能解决哪类新闻问题
  • 有一套可以不断抄改的脚本模板库
  • 能判断"这个问题该不该用代码解决"
  • 一个可以继续自学的真实起点
