📖 三、概念的通俗解释

函数是一段被起了名字、并且留好了出入口的代码。名字让这段代码可以被反复呼叫；入口是形参列表，用来把外面的数据递进去；出口是 return，用来把处理结果递出来。写 def clean_text(raw): 时，Python 并没有执行函数体里的任何一行，它只是把这段代码打包成一个函数对象，并让 clean_text 这个名字指向它。只有写成 clean_text(" 地铁调价 ")——名字后面跟上一对括号——才会真正发生调用：实参被绑定到形参，函数体从头执行一遍，return 把结果交回给调用处。

函数体里如果没有 return，函数依然会返回一个值，只是这个值是 None。这一点解释了初学者最常见的一类困惑：一个只在函数里 print 的函数，屏幕上明明有输出，写 x = 该函数(...) 之后 x 却是 None，因为 print 只负责把内容送到屏幕，不负责把内容交回调用处。

函数在 Python 里还是一等对象：函数名只是一个指向函数对象的名称，可以把同一个函数对象绑定到另一个名字上，也可以把函数当作值传来传去。同时，函数有自己的作用域：函数体内引用的名字按「由内向外」的顺序查找，而函数体内的赋值默认只写进最内层作用域——这两件事的不对称，是许多作用域错误的根源。

💡 一个类比 函数可类比为编辑部里一份写好并编号的「标准处理工序单」：工序单上写明了投入什么（形参）、怎么做（函数体）、产出什么（返回值）。工序单被写好放在抽屉里时（定义）什么都不会发生；每次照着它实际加工一份稿件时（调用），才会真正走一遍流程。同一份工序单可以加工一万份稿件，工序单本身不会因为加工过而改变。这一类比属于帮助理解的通俗化说法，非官方原文。
💡 一个类比 函数的返回值可类比为「交回给下一道工序的成品」，而 print 可类比为「在墙上贴一张进度公告」：公告人人可看，但不会被当作成品继续流转。凡是要让结果被后续步骤接着使用，就必须走返回值这条路。这一类比属于帮助理解的通俗化说法，非官方原文。

⚙️ 五、核心机制 / 组成

一条 def 语句把「名字」「入口」「流程」「出口」四件事绑定在一起；一次调用则把「实参绑定 → 执行函数体 → 交回返回值」三步连起来。下面三张表分别拆解这三组关系。

函数的组成部分

组成部分作用 / 说明
函数名在定义所在的作用域里，把函数名与函数对象关联起来。可用其他名称指向同一个函数对象，也可把函数对象作为值传递。命名通常使用小写加下划线。
形参列表写在括号内，声明函数可以接收哪些数据。形参是函数定义中的命名实体，实参是调用时真正传入的数据；一般同时出现「必选参数」与「可选参数」。
文档字符串函数体第一条语句若是字符串，它就是文档字符串，会被放入该对象的 __doc__ 属性，供代码内省与文档生成使用。
函数体缩进的语句块。定义时不执行，每次调用时从头执行一遍；每次调用都有自己的局部命名空间。
返回语句return 决定函数交回什么。不带表达式参数时返回 None；函数执行完毕退出也返回 None。即使没有 return，函数依然有返回值。

参数的五种写法与绑定规则

写法绑定规则常见用途需要注意
位置参数 clean_text(raw)按出现顺序依次绑定最必需、最常传的数据顺序错位时类型可能仍然合法，错误不会当场报出
关键字参数 clean_text(text, strip=True)按名称绑定，顺序不重要参数较多、只想改其中一两个关键字参数必须跟在位置参数后面；名称必须与形参匹配
默认参数 def f(raw, strip=True)调用时未传值就取默认值给出常用取值，简化调用默认值只在定义时求值一次；不要用列表、字典等可变对象作默认值
可变位置参数 *args收集所有剩余位置实参，装成一个元组参数个数不确定时通常放在形参列表的末尾；*args 之后的形式参数只能作关键字参数
可变关键字参数 **kwargs收集所有未匹配的关键字实参，装成一个字典转发配置项、透传参数必须是最后一个形参，*args 要写在它之前

作用域与名字查找

层次包含哪些名字生命周期
Local（局部）当前函数调用里的名字，含形参与函数体内赋值的名字函数被调用时创建，函数返回或抛出未处理的异常时被删除
Enclosing（外层函数）嵌套结构中外层函数的名字，「非局部、非全局」随外层函数的调用而存在
Global（模块全局）当前模块里定义的名字读取模块定义时创建，通常持续到解释器退出
Built-in（内置）如 len、print、内置异常的名称解释器启动时创建，永不被删除

查找从最内层作用域开始，逐层向外，内置名称最后被搜索；四层都没有找到时会引发 NameError。上述内容引自 Python 官方教程第 9 章「Python 作用域和命名空间」与第 4 章「定义函数」。global 语句表明某个名字属于全局作用域，引用与赋值都直接指向模块层；nonlocal 表明某个名字在外层作用域，并应在外层作用域中重新绑定。

🚀 六、一个具体应用场景

前 6 课留下的代码往往是一段一段散装的：清洗文本的几行、统计字数的几行、切分句子的几行、统计高频词的几行、生成短标题的几行。这些代码每次都跟着具体的那份稿件走，换一份数据就要复制一遍。把它们各自封装成一个函数之后，五段逻辑就变成五个可以反复呼叫的「工序」，一条记录跑完全流程只需要按顺序调用这五个名字。

下面这段代码可以直接运行，用到的全部是内置能力，不需要安装任何第三方库。

# news_text.py —— 把第 1~6 课的散装代码收拢成 5 个可复用函数

def clean_text(raw):
    """把一段原始稿件文本清洗成规范形式并返回。"""
    text = raw.replace("　", " ")     # 全角空格换成半角
    text = " ".join(text.split())     # 连续空白压缩成一个空格
    return text.strip()

def count_chars(text, exclude_space=True):
    """统计字符数；exclude_space 为 True 时不把空格计入。"""
    if exclude_space:
        return len(text.replace(" ", ""))
    return len(text)

def split_sentences(text, seps="。！？"):
    """按中文句末标点切句，返回句子列表。"""
    buf, out = "", []
    for ch in text:
        buf += ch
        if ch in seps:
            out.append(buf.strip())
            buf = ""
    if buf.strip():
        out.append(buf.strip())
    return out

def top_words(texts, n=3, win=2):
    """按固定长度滑窗粗粒度切词，返回出现次数最多的前 n 个 (词, 次数)。"""
    freq = {}
    for t in texts:
        for i in range(len(t) - win + 1):
            w = t[i:i + win]
            if " " in w:
                continue
            freq[w] = freq.get(w, 0) + 1
    return sorted(freq.items(), key=lambda kv: kv[1], reverse=True)[:n]

def make_title(text, max_len=12, ellipsis="…"):
    """把长标题截断为不超过 max_len 个字符的短标题。"""
    text = clean_text(text)
    if len(text) <= max_len:
        return text
    return text[:max_len] + ellipsis

# —— 一条记录跑完全流程 ——
raw  = " 　地铁票价调整方案 公布，首周客流下降 3%。  相关部门表示将继续观察。 "
text = clean_text(raw)
print(make_title(text))        # 地铁票价调整方案 公布，…
print(count_chars(text))       # 32（不计空格的字符数）
print(split_sentences(text))   # ['地铁票价调整方案 公布，首周客流下降 3%。', '相关部门表示将继续观察。']
print(top_words(["地铁调价 客流下降", "地铁调价 方案公布", "公交调价"]))

这一段是文章级别的示例，用于说明「把重复代码打包成函数」在流程上的收益，属于辅助理解示例，非某个来源的原文代码。其中 top_words 采用固定长度滑窗切分，只是一种便于演示的粗略做法；中文分词的正式工具见第 9 课列出的第三方库。

⚠️ 七、易混与边界

  • 函数名与函数调用是两件事。写 clean_text 只是引用这个函数对象，什么都不会发生；写成 clean_text(" 地铁调价 ") 才会执行函数体。把函数当参数传来传去时依赖的是前者，需要执行结果时用的是后者。
  • print 不是 return。屏幕上出现内容，说明 print 完成了「把内容送到标准输出」这件事；函数的返回值仍然由 return 决定。一个只 print 而不 return 的函数，返回值是 None，它无法被后续计算继续使用。
  • 没有 return 并不等于「没有返回值」。官方教程明确说明：即使没有 return 语句的函数也有返回值，这个值被称为 None；return 语句不带表达式参数时返回 None，函数执行完毕退出也返回 None。
  • 默认值只在定义时求值一次。默认值在定义作用域里的函数定义中求值，因此 i = 5 之后定义 def f(arg=i) 再把 i 改成 6，调用 f() 得到的仍是 5。默认值为列表、字典或类实例等可变对象时，还会产生跨调用的累加效果；常见做法是改用 None 作默认值，在函数体内判空后新建对象。
  • 函数内的赋值默认只写最内层作用域。不写 global 而直接给一个与全局同名的名字赋值，只会在函数内新建一个局部名字，模块层那个名字保持不变。global 使引用与赋值都指向模块全局作用域；要改写外层函数的名字则用 nonlocal。这类语句会让数据流向变得难以追踪，通常只在确有必要时使用。
  • 函数是一等对象。函数名只是指向函数对象的名称，同一个函数对象可以被绑定到其他名称上，也可以被赋值、放进容器、当作参数传给另一个函数。理解这一点，是理解后续 sorted(key=...)、装饰器、回调等写法的前提。
  • 纯函数与副作用是一条边界，不是一条禁令。把结果全部通过返回值交回、不修改函数之外状态的写法，通常称为纯函数，重复调用结果一致、更容易测试；而写文件、改全局变量、print 等对函数之外产生影响的行为属于副作用。读全局变量同样属于依赖外部状态，只是它不改变外部，因此更不容易被察觉。文档字符串的规范中要求记录「副作用」，正是因为没有副作用的函数并非全部情形。
