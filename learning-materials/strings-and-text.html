📖 三、概念的通俗解释

Python 里的字符串（str）就是「一段文字」，用成对的单引号 '...' 或双引号 "..." 标出来，两种写法的结果完全相同。官方教程明确写道：单引号与双引号唯一的区别，是不需要在单引号里转义双引号，反之亦然。引号里面即便是纯数字，例如 '1975'，得到的仍然是字符串而不是整数。

字符串是一串排列有序的字符，每个字符都有位置编号，从 0 开始。因此它支持两种基本取用方式：索引取单个字符（s[2]），切片取一段子串（s[2:5]）。官方教程给出了一个形象的读法：索引指向的是字符之间的空隙，第一个字符的左侧标为 0，最后一个字符的右侧标为字符串长度 n。

字符串最需要记住的性质是不可修改（immutable）。官方教程的原话是「Python 字符串不能修改」，为字符串中某个索引位置赋值会报 TypeError: 'str' object does not support item assignment。所有看起来像「修改」的操作——拼接、替换、去空白——实际上都是生成一个新字符串，原字符串原封不动。

💡 一个类比 字符串可类比为已经印刷装订好的一页报纸：字符的位置固定，可以按页码取阅（索引），也可以剪下连续的一段（切片），但已经印好的这一页无法涂改。要得到不同内容，只能重印一页新报纸——这正是 "J" + word[1:] 所做的事。这一类比属于帮助理解的通俗化说法，非官方原文。
💡 一个类比 文本清洗方法可类比为编辑部的校对工序：strip() 像修掉页边多余的空白，replace() 像统一标点体例，split() 像按句切条，join() 像把切好的条目按新规则重新排版。每一道工序都产出一份新稿样，而不是在旧稿上涂改。这一类比属于帮助理解的通俗化说法，非官方原文。

⚙️ 五、核心机制 / 组成

一个字符串对象可以拆成「值的存放方式」「取用方式」「加工方式」三层来理解。官方教程把字符串归入序列类型，因此它天然支持序列的索引与切片操作；而文本加工则由一批字符串方法提供。

组成与职责

组成部分作用 / 说明
字符序列字符串内部是一串有序字符，每个字符有一个位置编号。官方教程说明：单字符没有专用类型，就是长度为一的字符串。
引号与字面值写法成对的单引号或双引号标出字符串，两种写法结果完全相同；三重引号允许跨行并保留换行；字面值前加 r 得到原始字符串，反斜杠不再被当作转义引导符。

🚀 六、一个具体应用场景

从采编系统导出的一批稿件，往往是「脏」的：行首行尾带全角空格、句末混用半角与全角标点、数字夹在全角字符里、还有连写的感叹号。这样的文本直接进入字数统计或关键词检索，会得到错误的计数结果。第 2 课的练习就是写一段清洗逻辑，把它整理成规范文本。 

# 场景：清洗一条从采编系统导出的脏稿件
raw = "　 地铁票价调整！！记者３人受伤，现场秩序正常。 　"

# 第 1 步：strip() 去掉首尾空白（默认移除空白字符，无需传参）
s = raw.strip()
print("去皮 →", repr(s))

# 第 2 步：replace() 把全角数字换成半角，便于后续统计
s = s.replace("３", "3")

# 第 3 步：replace() 压缩重复标点
s = s.replace("！！", "！")
print("标点 →", s)

# 第 4 步：split() 按句末标点切成短句列表
sentences = s.split("。")
print("句数 →", len(sentences))

# 第 5 步：join() 用统一分隔符拼回一行，方便写入发版台账
parts = [x.strip() for x in sentences if x.strip()]
ledger_line = " ｜ ".join(parts)
print("台账 →", ledger_line)

# 字符串不可修改：下面这行会报 TypeError，必须改成重新赋值
# s[0] = "新"   →  TypeError: 'str' object does not support item assignment
s = "新" + s[1:]        # 正确写法：拼接生成新字符串再赋回同名变量
print("改首字 →", s)

# 顺带一提：字数统计用 len()，它数的是字符个数
print("字数 →", len(s))

这一段是文章级别的示例，用于说明清洗流程与各方法的分工，属于辅助理解示例，非某个来源的原文代码。

⚠️ 七、易混与边界

  • 字符串不可修改，所有方法都返回新值。官方教程写明「Python 字符串不能修改，是 immutable 的」，word[0] = "J" 会直接抛 TypeError。由此带来一个常见疏漏：s.strip() 本身不会改变 s，必须写成 s = s.strip() 才生效。
  • 切片越界不报错，索引越界会报错。官方教程给出的例子是：word[42] 触发 IndexError，而 word[4:42] 与 word[42:] 都能正常返回（分别得到一段子串与空字符串）。切片会自动处理越界索引，因此「切片结果为空」通常不是报错，而是一个需要留意的信号。
  • + 只能拼接同类型序列，不能把字符串与数字相加。"字数：" + 12 会抛 TypeError，因为加法要求两个操作数要么都是数字，要么都是同一类型的序列。正确做法是先 str(12)，或改用 f-字符串 f"字数：{12}"。另需注意：字符串 * 整数表示重复，官方教程例子为 3 * 'un' + 'ium' 得到 'unununium'。
  • strip() 默认去的是空白，不是「任意多余字符」。官方文档说明：chars 省略或为 None 时默认移除首尾的空白字符；一旦传入参数，该参数被理解为字符集合而非前缀或后缀，其所有组合都会被移除。'www.example.com'.strip('cmowz.') 得到 'example' 正是这个原因。它也不会移除字符串内部的空白。
  • find() 与 in 用途不同，也不与 index() 等价。find() 找不到时返回 -1，从不抛异常；官方文档建议只判断存在性时改用 in。而同族的 index() 在找不到时会抛 ValueError，两者不可互换。
  • 单引号与双引号没有功能差异，三重引号才有。官方教程备注说明：单引号与双引号里 \n 等特殊字符意义完全一样，唯一区别是不需要在单引号里转义双引号。因此「用双引号更正式」之类的说法在 Python 中并不成立。三重引号的区别在于允许未转义的换行并会将其保留。

✅ 核查说明：本节六条均以 Python 官方文档为依据。不可修改性质、IndexError 与切片越界的差别、+ 与 * 的行为、单双引号区别，见官方教程《Python 速览》3.1.2 节；strip() 的 chars 语义与 find() 返回 -1 见《内置类型 · 字符串方法》；index() 抛 ValueError 的对比见同页 str.index() 条目；+ 要求操作数为同类型序列见《表达式》6.7 节。
