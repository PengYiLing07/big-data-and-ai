📖 三、概念的通俗解释

Python 的变量不是「装东西的盒子」，而是贴在数据上的名字标签。写 lead = "地铁票价调整" 时，Python 先在内存里创建字符串对象 "地铁票价调整"，然后让 lead 这个名字指向它。之后再写 lead = "小区加装电梯"，并不是把盒子里的旧东西倒掉换成新的，而是让 lead 这个标签改贴到另一个新对象上——原来的字符串对象如果没人引用，会被自动回收。

每个值都自带一个类型，类型决定了这个值能做什么。"1975" 是字符串，它可以拼接、可以取长度，但不能做减法；1975 是整数，它能参与算术运算。类型跟着值走，不跟着变量走——同一个变量名先后指向字符串和整数，是完全合法的。

💡 一个类比 变量可类比为贴在物品上的便利贴：便利贴上写的是一个名字，物品本身才是数据。同一样物品可以贴多个便利贴（多个变量指向同一个对象），同一张便利贴也可以被撕下来贴到另一样物品上（重新赋值）。这一类比属于帮助理解的通俗化说法，非官方原文。
💡 一个类比 类型可类比为容器的规格说明：字符串是「文字罐」，整数和浮点数是「数字罐」，布尔是「开关」。规格不同，能做的动作就不同——把文字罐直接倒进算术运算里，Python 会明确报错而不是猜用户想干什么。这一类比属于帮助理解的通俗化说法，非官方原文。

⚙️ 五、核心机制 / 组成

一条赋值语句 name = value 实际包含「求解右侧」「创建/引用对象」「建立名字指向」三步。理解这三部分的职责划分，是理解一切后续语法（循环、函数、模块）的前提。

组成部分作用 / 说明
变量名程序员起的标识符，用于在代码中引用数据。Python 3 允许标识符使用中文字符，但通用实践是使用英文小写加下划线，遵循 PEP 8 命名规范。
指向（引用）名字与对象之间的关联关系。= 建立或改变这条指向；重新赋值只是换指向，不改动原对象。
值对象真正占用内存的数据。整数、浮点数、字符串、布尔值都是对象，各自带有类型信息。
类型决定该值支持哪些操作、能被哪些函数接受、如何与其他类型运算。类型属于值，不属于变量名。

🚀 六、一个具体应用场景

一篇稿件从采写系统导出后，标题、字数、阅读量、是否为草稿往往混在一个文本文件里。要让程序能自动排序、统计和判断，第一步就是把每个字段装进合适类型的变量——这正是第 1 课「稿件字数统计器」要做的事。 

# 从一行文本里取出字段，装进不同类型变量
title    = "地铁票价调整方案公布"   # str：文字
chars    = 16                        # int：字数
ratio    = 0.68                      # float：通读完成比例
is_draft = False                     # bool：是否草稿

# 类型正确时，运算才成立
print(title, "字数：", chars)
print("进度：" + str(round(ratio * 100)) + "%")   # 必须先转成字符串才能拼接

# 假设字数是从文件里读来的，它会默认是字符串
chars_from_file = "16"
chars = int(chars_from_file)         # 显式转换后才能参与计算
print(chars + 4)                     # 20

这一段是文章级别的示例，用于说明类型正确性与后续所有数据处理的关系，属于辅助理解示例，非某个来源的原文代码。

⚠️ 七、易混与边界

  • = 不是数学里的「等于」。它表示「让左边的名字指向右边算出来的值」，因此 x = x + 1 在 Python 里完全合法（先算右边的旧值加一，再把名字指向新结果）。要判断相等，用的是 ==。
  • "1975" 与 1975 是两种不同的东西。前者是长度为 4 的字符串，len() 得 4；后者是整数，能参与算术。混用的典型后果是 "100" + 1 直接抛 TypeError，而不是得到 101。从文件读进来的内容默认都是字符串，这一步转换最容易被漏掉。
  • bool 是 int 的子类型。True 和 False 在几乎所有上下文中的表现等同于 1 和 0，参与运算时也按 1 / 0 处理；唯一的例外是被转换成字符串时，得到的是 "True" / "False"。因此 True + True 的结果是 2。
  • 浮点数不适合用 == 直接比较。受二进制表示限制，0.1 + 0.2 == 0.3 的结果是 False。需要比较时常见做法是判断差值是否足够小，或改用 decimal 模块。该限制源自官方文档《浮点算术：争议和限制》。
  • 变量在赋值之前不能使用。访问一个未定义的变量会直接报 NameError: name 'n' is not defined，这是初学者最常见的报错之一。使用前必须让它先指向某个值。

✅ 核查说明：本节五条均以 Python 官方文档为依据。= 与 == 的区别、NameError 的触发条件见官方教程《Python 速览》3.1 节；bool 是 int 子类型这一表述见官方文档《数据模型》3.2.4.1；浮点精度限制见官方教程《浮点算术：争议和限制》。
