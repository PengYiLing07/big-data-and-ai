📖 三、概念的通俗解释

字典（dict）保存的是「键 → 值」的对应关系。官方术语表对它的定义是：一个关联数组，其中的任意键都映射到相应的值；键可以是任何具有 __hash__() 和 __eq__() 方法的对象。用花括号写出来就是 {"标题": "地铁票价调整方案公布", "字数": 128}，其中 "标题" 和 "字数" 是键，冒号后面的是值。与列表按位置取元素不同，字典按名字取值，因此不必记住某项排在第几位。

读取字典有一个常见的区别：用方括号读取不存在的键会直接抛 KeyError；而 d.get(k) 在键不存在时返回 None，也可以指定一个默认值，例如 d.get(k, 0)。做计数时 counts[w] = counts.get(w, 0) + 1 是最常见的写法之一。

集合（set）是「不重复元素组成的无序多项集」。官方教程的表述是：集合是由不重复元素组成的无序多项集，基本用法包括成员检测和消除重复元素，集合对象还支持合集、交集、差集和对称差集等数学运算。注意创建空集合只能用 set()，因为 {} 创建的是空字典。

💡 一个类比 字典可类比为一份对照卡片盒：盒子里每一张卡片的正面是一个名字（键），背面是它对应的内容（值）；按名字抽卡很快，但卡片本身没有「第一张、第二张」的概念。这一类比属于帮助理解的通俗化说法，非官方原文。
💡 一个类比 集合可类比为一份「去重后的名单」：每个名字在名单上只出现一次，名单内部没有排序；判断某人在不在名单上很快，而对两份名单做交集就是「两边都出现过的名字」。这一类比属于帮助理解的通俗化说法，非官方原文。

⚙️ 五、核心机制 / 组成

字典与集合同属「靠哈希值定位条目」的一类结构：字典保存的是键与值的对应关系，集合保存的只有键本身。下表先给出字典的组成，再给出两者的常用操作。

字典的组成

组成部分作用 / 说明
键（key）用来标识条目的值，必须可哈希。同一个字典中键不会重复；重复指定同一个键时，最后给出的值生效。
值（value）与键对应的内容，可以是任何对象，包括列表、字典等可变对象。
条目（item）一对「键 + 值」。len(d) 返回的是条目数量。
字典视图keys()、values()、items() 返回的对象称为字典视图：它们提供字典条目的一个动态视图，字典改变时视图也会相应改变。
顺序字典保持插入顺序。官方文档说明，该特性自 Python 3.7 起被正式宣布为语言规范的组成部分。

「可哈希」到底在要求什么

说法含义
可哈希对象具有在其生命期内绝不改变的哈希值（需要有 __hash__() 方法），并且可以同其他对象进行比较（需要有 __eq__() 方法）。可哈希性使得对象能够作为字典键或集合成员使用。
哪些可用大多数不可变内置对象都是可哈希的：数字、字符串、元组（且内部元素也都可哈希）、frozenset。
哪些不可用可变容器不可哈希：列表、字典、集合。把它们当键会抛 TypeError: unhashable type。

🚀 六、一个具体应用场景

统计一段语料里每个词出现了多少次、哪几个词出现得最多，是文本分析里最基础的一步；它同时也是后续给文本做特征时的常见操作。——这正是第 5 课「评论文本词频统计」要做的事。下面的代码可以直接运行。 

from collections import Counter

text = "地铁 票价 调整 地铁 票价 地铁 公交"

# 方式一：用普通字典手动计数
# 先用 get(w, 0) 取默认值，避免首次遇到某个词时抛 KeyError
counts = {}
for w in text.split():
    counts[w] = counts.get(w, 0) + 1
print(counts)   # {'地铁': 3, '票价': 2, '调整': 1, '公交': 1}

# 方式二：用 Counter，写法更短；查询不存在的键返回 0
counts = Counter(text.split())
print(counts.most_common(2))   # [('地铁', 3), ('票价', 2)]

# 只看出现次数最多的一个词
top_word, top_n = counts.most_common(1)[0]
print(top_word, top_n)         # 地铁 3

# setdefault：把「词 → 它出现过的位置」记下来
index = {}
for i, w in enumerate(text.split()):
    index.setdefault(w, []).append(i)
print(index["地铁"])   # [0, 3, 6]

# 集合去重：先看这段语料一共用到多少个不同的词
words = text.split()
uniq = set(words)
print(len(uniq))               # 4

# 集合运算：停用词与正文词的差集
stopwords = {"的", "了", "在"}
print(set(stopwords) & set(words))   # set()——两者没有共同元素
content_words = set(words) | set(stopwords)
print(len(content_words))            # 7

这一段是文章级别的示例，用于说明字典与集合在真实文本统计中的组合方式，属于辅助理解示例，非某个来源的原文代码。

⚠️ 七、易混与边界

  • {} 是空字典，不是空集合。官方教程明确指出：创建集合用花括号或 set() 函数，注意创建空集合只能用 set()，不能用 {}，{} 创建的是空字典。因此 type({}) 得到 dict，type(set()) 得到 set。
  • 键必须可哈希，因此列表不能当键。官方术语表对「可哈希」的说明是：可哈希性使得对象能够作为字典键或集合成员使用；可变容器（例如列表或字典）都不可哈希。把列表当键会直接抛 TypeError。需要把「一组值」当作键时，可以改用元组。
  • 用方括号读不存在的键会抛 KeyError，用 get() 不会。这是初学者最常见的报错之一。d.get(k) 返回 None，d.get(k, 0) 返回 0；做计数时后者几乎是标准写法。
  • get() 与 setdefault() 的分工不同。get() 只负责读取，不改变字典；setdefault() 在键不存在时会顺手把默认值写进字典。前者适合做统计取值，后者适合「把多个条目按同一个键归并」这类需要写回的场景。
  • 字典的顺序是有保证的，集合的顺序没有。官方文档明确说明，字典保持插入顺序这一特性自 Python 3.7 起成为语言规范的正式组成部分；而关于集合，官方教程写道：由于集合是无序的，在迭代或打印它们时可能会以不符合预期的顺序输出元素。需要固定顺序时，可配合 sorted() 使用。
  • 字典视图是动态的，不是快照。官方术语表的表述是：它们提供了字典条目的一个动态视图，这意味着当字典改变时，视图也会相应改变。因此遍历 d.items() 的同时增删条目会带来问题；需要固定下来时先转成 list()。
  • 字典的键不能重复，集合的元素也不能重复。官方文档指出，字典中重复键之间的冲突不会被检测，指定键所保存的最后一个值将成为最终的值。集合同理，重复写入不报错，但只保留一个。
