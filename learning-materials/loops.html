📖 三、概念的通俗解释

循环让同一段代码被重复执行多次。Python 提供两种循环语句。for 用于对一个可迭代对象中的元素进行迭代：把序列里的元素一个个取出来，每取一个就执行一遍循环体，取完就结束。官方语言参考给出的过程是：先对表达式求值一次，得到一个可迭代对象；为它创建一个迭代器；把迭代器给出的第一项按赋值规则赋给目标变量，然后执行子句体；对每一项重复这个过程；迭代器耗尽时，可选 else 子句（若存在）被执行，循环终止。

while 则是条件驱动的：重复地检验表达式，只要其值为真就执行循环体；一旦表达式的值变为假（这可能在第一次检验时就发生），若存在 else 子句它会被执行，然后循环终止。

Python 的循环还有一个容易被忽略的语法前提：缩进即语法块。官方教程说明，循环体是缩进的，缩进是 Python 组织语句的方式，同一块语句的每一行的缩进必须相同。PEP 8 给出的约定是每个缩进层级使用 4 个空格，并且不允许混用制表符与空格。

💡 一个类比 for 可类比为按一份名单逐一点名：名单是固定的，点完就结束；while 可类比为「只要门外还有人排队就继续叫号」：重复次数事先不写死在代码里，由条件决定何时收工。这一类比属于帮助理解的通俗化说法，非官方原文。
💡 一个类比 break 可类比为中途直接合上名单不点了，continue 可类比为这一行先跳过、继续点下一行。这一类比属于帮助理解的通俗化说法，非官方原文。

⚙️ 五、核心机制 / 组成

一条循环语句可以拆成「一个可迭代对象或条件 + 一个缩进块 + 若干可选的控制子句」三部分。下表先给出部件职责，再给出常用写法与边界。

循环的组成部件

组成部分作用 / 说明
可迭代对象 / 条件for 的 in 右侧可以是列表、字符串、字典、range() 等任何可迭代对象；while 的判断依据是一个表达式，其值为真则继续。
目标变量for 中承接当前元素的名字，按赋值规则被逐项赋值。官方说明指出：循环对目标变量的赋值会覆盖此前对它的所有赋值，包括在循环体中做的赋值；循环结束后这个名称仍然存在。
循环体（缩进块）被重复执行的语句组。缩进是 Python 组织语句的方式，同一块语句的每一行缩进必须相同。
控制子句break、continue、可选的 else 子句，用来改变默认的「从头走到尾」的执行路径。

常用写法与边界

写法产出 / 行为需要注意
for x in seq:逐个取出 seq 的元素序列在循环期间被改动会打乱遍历进度
for i in range(n):0, 1, …, n-1含起点不含终点；range 是惰性的不可变整数序列，不一次占用 n 个元素的内存
for i in range(a, b, s):从 a 开始，步长 s，到 b 之前停止步长为负时表示倒数；步长不能为 0
for i, x in enumerate(seq):每轮得到 (序号, 元素)默认从 0 开始，可用 start=1 改为从 1 开始编号
for a, b in zip(s1, s2):把两个序列逐项配成元组长度不同时按较短的截断，多余部分被丢弃；strict=True 可改为长度不一致就报错
for x in sorted(seq):按排序后的顺序遍历不改动原序列，返回一个重新排序的序列
for x in set(seq):去重后遍历集合无序，遍历顺序通常与书写顺序不同
while cond:条件为真就重复执行循环体内必须存在让条件趋向于假的因素，否则会一直执行下去
break终止最近一层的循环，且不执行该循环的 else在嵌套循环中只跳出最内层那一层
continue跳过本轮剩余语句，转往下一项或下一轮在 while 中会回到条件检验处，不会跳过条件判断
for/while ... else:循环未被 break 终结时执行 else官方给出的类比是：它更像 try 的 else，而不是 if 的 else
pass什么也不做用于占位，让尚未写完的循环体在语法上合法

上表主要依据 Python 官方教程《4. 更多控制流工具》、官方语言参考《8. 复合语句》与《5. 数据结构 · 循环的技巧》整理。

🚀 六、一个具体应用场景

一条稿件的处理流程通常是这样：拿到一批标题和它对应的评论，逐条编号打印，逐条配对检查，遇到明显不合格的就跳过，找到第一条需要重点关注的标题就停下来。——这正是第 4、6 课「批量稿件巡检」要做的事。下面的代码可以直接运行。 

titles = [
    "地铁票价调整方案公布",
    "小区加装电梯补贴细则出台",
    "市图书馆延长夜间开放时间",
]
comments = [
    "支持，希望早点执行",
    "电梯费用怎么分摊？",
    "夜间开放太好了",
]

# enumerate：同时拿到序号和内容，start=1 让编号从 1 开始
for i, t in enumerate(titles, start=1):
    print(f"第 {i} 条｜{t}")

# zip：把标题与评论一一配对；两个列表等长时正好配完
for t, c in zip(titles, comments):
    print(t, "→", c)

# for...else：找第一条超过 10 个字的标题
# 命中就 break；全部走完仍未命中，才轮到 else 出场
for t in titles:
    if len(t) > 10:
        print("找到长标题：", t)
        break
else:
    print("没有超过 10 个字的标题")

# while：处理一个事先不知道有多少条的待审队列
queue = ["待审 1", "待审 2", "待审 3"]
while queue:                          # 空列表为假，队列清空即停下
    item = queue.pop(0)
    if item == "待审 2":
        continue                      # 跳过这一条，剩余语句不执行
    print("已处理：", item)

# 排查长标题时不要一边遍历一边删原列表，改为写入新列表
long_titles = []
for t in titles:
    if len(t) >= 10:
        long_titles.append(t)
print(long_titles)

这一段是文章级别的示例，用于说明循环在真实稿件流程中的组合方式，属于辅助理解示例，非某个来源的原文代码。

⚠️ 七、易混与边界

  • break 与 continue 的差别是「结束整个循环」还是「只结束本轮」。官方语言参考的表述是：循环体中的 break 在执行时将终止循环且不执行 else 子句体；continue 在执行时将跳过子句体中的剩余部分并转往下一项继续执行（while 中则返回检验表达式）。
  • 循环的 else 与 if 的 else 不是一回事。官方文档特别指出：当配合循环使用时，else 子句更像是 try 语句的 else，而不像 if 的相应子句——try 的 else 在未发生异常时运行，循环的 else 在未发生 break 时运行。因此它常被用来表达「找遍了都没找到」。return 或抛出异常同样会跳过 else。
  • for 循环体里给目标变量重新赋值不会改变遍历进度。官方文档的例子是：在 for i in range(10) 的循环体里写 i = 5，这一赋值不会影响循环，因为它会被 range 对象中的下一个索引所覆盖。
  • 一边遍历一边删元素会漏掉若干项。官方教程给出的建议是：在循环中修改列表的内容时，创建新列表比较简单，且安全；其示例是把合格的数据 append 到一个新的 filtered_data 列表里，而不是就地删除。
  • zip() 的长度以短的一方为准。官方文档的示例显示，list(zip(range(3), ['fee','fi','fo','fum'])) 只得到三个元组，第四个元素被丢弃；若希望长度不一致时报错，可使用 strict=True。
  • while 循环的边界是「条件必须有变假的机会」。官方教程用斐波那契数列演示 while 时说明，只要条件为真就执行。若循环体内没有任何让条件趋向于假的改动，循环不会自行结束。这是初学者最常遇到的一类问题。
  • 缩进不是排版偏好，而是语法。官方语言参考指出，子句体要么是与句头同行的一条或由分号分隔的多条简单语句，要么是缩进的一行或多行语句；只有后一种形式才能包含嵌套的复合语句。PEP 8 约定每个缩进层级用 4 个空格，并且 Python 不允许混用制表符和空格做缩进——混用会引发 TabError 一类的错误。

✅ 核查说明：本节七条均以 Python 官方文档为依据。break / continue / 循环 else 的语义见官方语言参考《8. 复合语句》8.2 与 8.3 节，以及官方教程《4. 更多控制流工具》4.4、4.5 节；循环中修改列表的建议与 zip()、enumerate() 的示例见《5. 数据结构 · 循环的技巧》；while 的说明见官方教程《3. Python 速览》3.2 节；缩进与命名规范见 PEP 8。
