📖 三、概念的通俗解释

matplotlib 是 Python 最常用的绘图库。官方文档给出的核心模型很简洁：图形画在 Figure 上，一张 Figure 可以包含一个或多个 Axes——Axes 指「一块用于绘图的区域」，而不是「坐标轴（axis）的复数」。每个 Axes 通常带有两个（三维图是三个）Axis 对象，负责刻度与刻度标签；此外还带有标题、x 轴标签、y 轴标签等元素。

理解这个层次，就能明白为什么同一个效果会有两种写法。第一种是显式（面向对象）接口：先用 fig, ax = plt.subplots() 拿到画布和绘图区域，再调用 ax.plot(...)、ax.set_title(...) 这样的方法。第二种是隐式（pyplot）接口：直接写 plt.plot(...)、plt.title(...)，由 pyplot 在背后自动创建并记住「当前 Figure」和「当前 Axes」。官方文档的说明是：复杂图形、以及需要被复用的函数与脚本，一般建议使用显式接口；而快速交互式的探索，pyplot 简写更省事。

之所以要强调这一点，是因为 pyplot 维护的是一份全局状态——它记得最近创建的 Figure 与 Axes，后续 plt.* 调用都作用在它认为「用户想要的那个」对象上。这带来了一种常见故障：连续画多张图时，第二张图的元素画到了第一张上，或者修饰语句作用到了错误的子图上。显式保存 fig 与 ax，然后调用 ax 上的方法，可以规避这类问题。

💡 一个类比 Figure 可类比为一张画纸，Axes 可类比为画纸上用铅笔框出来的若干块画格；同一张纸上可以并排放好几个画格，每个画格各有自己的边框、刻度和标题。画数据时是往某个具体画格里画，而不是「往纸上随便画」。这一类比属于帮助理解的通俗化说法，非官方原文。
💡 一个类比 pyplot 简写接口可类比为「默认接着上一次那块画格继续画」：说「画一条线」时，系统会自动挑一块画格；而面向对象接口相当于每次都明确指定「画在第 2 格的这块区域里」。前者省字，后者不容易画错地方。这一类比属于帮助理解的通俗化说法，非官方原文。

⚙️ 五、核心机制 / 组成

matplotlib 的图形由四层对象搭起来，一次绘图调用实际是在某个 Axes 上添加一个 Artist。理解这四层的分工，就能读懂官方文档与网上大多数示例代码。

组成部分作用 / 说明典型写法
Figure整张画布（在交互环境中对应一个窗口或一块内嵌区域）。它管理所有子 Axes，以及标题、图例、颜色条等「图级」的特殊 Artist。fig = plt.figure()
fig, ax = plt.subplots()
Axes一块绘图区域，是配置图形的主要入口：加数据、控制坐标轴范围、加标签都在它上面完成。注意它不是 axis 的复数。ax.plot(...)
ax.set_title("...")
Axis负责刻度位置与刻度标签文字，由 Locator 决定刻度打在哪里、Formatter 决定刻度怎么显示。一般无需直接操作，由 Axes 间接管理
Artist画面上一切可见元素都是 Artist，包括 Figure、Axes、Axis 自身，以及文字、折线、方块、图例框等。大多数 Artist 归属于某一个 Axes，不能同时被多个 Axes 共用。line, = ax.plot(...) 拿到的是 Line2D（一种 Artist）

四种常用图形与它们的适用场合

函数主要参数适合表达什么
plot(x, y)x、y 数据；可加 label 以便图例识别折线：随顺序变化的量，例如发布时间轴上的每日评论量。只传一组数据时，x 会自动生成为 0、1、2……
bar(x, height)x 为类别标签或位置，height 为柱高，width 为柱宽柱状图：类别之间的量值比较，例如词频 Top 10 排行。x 可直接传一列类别名。
hist(x, bins=...)x 为一组数值，bins 为分箱数或分箱边界直方图：一组数值落在各区间内的频数，例如评论文本长度分布。bins 越大柱子越细。
scatter(x, y)x、y 数据；s 控制点大小，c 控制点颜色散点图：两组数值之间的关系，或按第三个变量给点上色的分布图。

修饰、布局与输出

环节写法作用 / 说明
文字修饰ax.set_title("...")给该 Axes 加标题。
ax.set_xlabel("...") / set_ylabel("...")加 x 轴、y 轴标签。柱状图与直方图的 y 轴通常是「频数 / 条数」，需要写明。
ax.legend()显示图例。图例内容来自绘制时传入的 label；不传任何参数时会自动收集带标签的元素，若没有任何带标签的元素，会得到空图例并给出提示。
中文字体rcParams["font.family"]官方推荐的做法：把支持所需字形的字体名放进字体族列表，并建议在末尾附加一个通用族作为兜底。
rcParams["font.sans-serif"]另一种写法：先设 font.family = ["sans-serif"]，再改写 sans-serif 这个别名指向的字体列表。
rcParams["axes.unicode_minus"]控制负号是否使用 Unicode 减号，默认 True。字体不含该字形时可设为 False，改用普通连字符。
布局fig, axs = plt.subplots(2, 2)一次创建一张 Figure 和一组子图；返回的 axs 按行列组织，可用 axs[0, 1] 这样的下标访问具体一块。
layout="constrained"让子图间距自动避让标签，减少文字被裁切的情况。
输出plt.savefig("out.png", dpi=200, bbox_inches="tight")把当前图形保存为文件。官方参数表说明：dpi 默认取图形自身的 dpi，bbox_inches="tight" 表示只保存图形的紧凑边界，可去掉多余留白。
plt.show()在交互环境中显示图形。官方《Quick start guide》提示：在部分环境（如 Jupyter）中可以不写这一句，图形会自动显示。
与 pandas 衔接df.plot(kind="bar")pandas 的绘图方法是对 matplotlib 的封装，官方文档明确说明「默认使用 matplotlib」作为后端，并返回 Axes 对象，因此可以继续用 ax.set_title(...) 修饰。

以上对象定义、参数名与默认值均来自 matplotlib 官方《Quick start guide》《Matplotlib Application Interfaces (APIs)》《Backends》《Text properties and layout》《Customizing Matplotlib》及 pyplot 各函数参考页，可经第九节链接逐条核查。

🚀 一个具体应用场景

上一份资料里已经算出了两个结果：评论表中的词频排行，以及评论文本长度的分布。编辑部需要为稿件配两张图——一张展示最常出现的关键词，一张展示评论长度的集中区间。下面这一段把中文字体设置、柱状图、直方图与文件导出串起来。 

# 场景：把词频排行与文本长度分布画成图，直接作为稿件配图
import matplotlib
import matplotlib.pyplot as plt
import pandas as pd

# ① 中文显示：默认字体不含中日韩字形，需指定一个含中文字形的字体
matplotlib.rcParams["font.family"] = ["Microsoft YaHei", "sans-serif"]
matplotlib.rcParams["axes.unicode_minus"] = False   # 负号改用普通连字符

# ② 准备数据：词频排行（Series）与文本长度（Series）
df = pd.read_csv("comments.csv", encoding="utf-8")
df["文本长度"] = df["评论内容"].str.len()

word_freq = pd.Series({"地铁": 128, "票价": 96, "换乘": 74,
                      "通勤": 61, "早高峰": 45}).sort_values()

# ③ 建图：显式拿到 fig 与 ax，后续修饰都作用在这块 Axes 上
fig, axs = plt.subplots(1, 2, figsize=(11, 4), layout="constrained")

# ④ 左图：词频排行用横向柱状图，类别多时比竖向更易读
axs[0].barh(word_freq.index, word_freq.values, color="#2f6fed")
axs[0].set_title("评论关键词 Top 5")
axs[0].set_xlabel("出现次数")

# ⑤ 右图：文本长度分布用直方图，bins 决定分箱粗细
axs[1].hist(df["文本长度"].dropna(), bins=20, color="#7c5cff")
axs[1].set_title("评论文本长度分布")
axs[1].set_xlabel("字数")
axs[1].set_ylabel("评论条数")

# ⑥ 输出：先 savefig 存文件，再 show 显示；dpi 与紧凑边界便于稿件排版
plt.savefig("评论配图.png", dpi=200, bbox_inches="tight")
plt.show()

这一段是文章级别的示例，用于说明各环节在流程中的位置，属于辅助理解示例，非某个来源的原文代码。其中字体设置写法依据 matplotlib 官方《Text properties and layout》「Text with non-latin glyphs」一节，savefig 参数依据官方 pyplot.savefig 参考页。

⚠️ 七、易混与边界

  • 图「不显示」通常是两类原因。一类是代码里既没有调用 plt.show()、也没有调用 savefig()，脚本运行完就结束了；另一类是所在后端是非交互后端（如 Agg，只能写文件、不能开窗口），此时官方文档建议的排查办法是先打印 matplotlib.get_backend() 看当前用的是哪个后端。官方《Backends》一章还专门列了「图形窗口不显示」的调试步骤。
  • 中文乱码与负号乱码是两个独立的设置。中文方块源于所选字体缺少中日韩字形，官方给出的做法是设置 font.family（推荐）或在 font.sans-serif 别名里加上含中文字形的字体；负号异常源于 axes.unicode_minus 默认为 True，即使用 Unicode 减号字符，若该字形不在所选字体里就会显示异常，需把它设为 False。常见误解是「设了中文字体，负号问题就一起解决了」——如果换上的中文字体恰好含减号字形，看起来像是顺带修好了，但那是巧合而非同一处设置。
  • pyplot 的全局状态会互相污染。官方《Pyplot tutorial》说明：pyplot 保留了「当前 Figure」与「当前 Axes」的概念，所有绘图函数都作用于当前 Axes，gca() 返回当前 Axes、gcf() 返回当前 Figure。因此连续绘制多张图时，若不显式保存 fig / ax，第二张图很容易画到第一张上。官方在《Matplotlib Application Interfaces (APIs)》中给出的建议是：一开始就显式创建并保存对象引用。
  • ax.plot() 与 plt.plot() 不是两套库。官方接口对照表列出了二者的一一对应关系：绘图函数同名同参（ax.plot(x, y) 与 plt.plot(x, y)），取属性时 Axes 用 get_ 前缀（ax.get_xlabel()）而 pyplot 用同名函数（plt.xlabel()），设属性时 Axes 用 set_ 前缀（ax.set_xlabel("time")）而 pyplot 用同名函数（plt.xlabel("time")）。理解这个对应关系，就能在两种风格的示例代码之间自由翻译。
  • savefig() 与 show() 的顺序值得注意。官方 FAQ 在「不打开窗口生成图片」一条中给出的做法是：调用 savefig 之后要 close，否则 pyplot 会一直保留对未显示图形的引用，形成内存占用。也就是说，保存与显示是两件事，哪个在前、是否需要关闭，取决于运行环境。
  • matplotlib 不能替数据质量负责。图的形状取决于清洗与统计口径：bins 取得太粗会掩盖分布形态，太细会显得杂乱；文本长度如果没去掉空白与网址，直方图整体会向右偏移。边界在于——图形只是呈现方式，口径问题需要在数据环节解决。

✅ 核查说明：本节六条的技术结论均以 matplotlib 官方文档为依据。后端与窗口不显示见《Backends》；中文与非拉丁字形见《Text properties and layout》「Text with non-latin glyphs」；axes.unicode_minus 见《Customizing Matplotlib with style sheets and rcParams》；pyplot 全局状态见《Pyplot tutorial》；两种接口的对照见《Matplotlib Application Interfaces (APIs)》；savefig 与关闭图形见官方 FAQ。具体链接见第九节。
